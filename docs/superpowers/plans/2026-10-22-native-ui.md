# Native Go UI Implementation Plan

> Execute inline using superpowers:executing-plans, with native UI tests and a final independent review.

**Goal:** Replace the WebView interface with pure Go mygo/ui while preserving appearance and all SSH workflows.
**Architecture:** Typed backend interface, main-thread native view/controller, worker completion queue; reuse desk.Service unchanged.
**Tech stack:** Go 1.27.1, mygo v0.5.5 ui, native Windows renderer, existing crypto/SSH backend.
**Spec:** ../specs/2026-10-22-native-ui-design.md

## Constraints and review focus

No webview creation or frontend RPC in main. No real server changes during testing. Preserve host trust confirmation before password, token invalidation, secret cleanup and async thread safety. Small windows must show the complete form. Check expired tokens, late results after cancellation, busy dialog dismissals, close during work, and stored-but-unverified receipts.

- [ ] Add internal/nativeui backend interface, app controller, completion queue and compact native shell.
- [ ] Test navigation, filter, read-only startup, worker completions and minimum-size form bounds; observe failure before implementation.
- [ ] Keep layout/style helpers separate from actions and dialogs.

- [ ] Add installation/trust, delete/recreate, transfer and detail dialogs using typed desk requests.

- [ ] Replace main.go web embed/SetFrontend/BindAs/URL with Content ui.View; embed native app icon only.
